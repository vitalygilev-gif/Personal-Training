# Трекер формы — установка на iPhone

Это офлайн-приложение (PWA). После установки оно работает полностью без интернета:
весь код хранится на телефоне, все записи — только на вашем устройстве, никуда не
отправляются и ни к какому сервису не привязаны.

Сеть нужна один раз — чтобы выложить файлы на бесплатный хостинг и открыть ссылку
на телефоне. Дальше интернет не требуется.

## Шаг 1. Выложить файлы (один раз, ~5 минут)

### Вариант A — GitHub Pages (рекомендую)

1. Зайдите на github.com (аккаунт бесплатный).
2. Создайте репозиторий: **New repository** → имя, например `forma` → Public → Create.
3. На странице репозитория: **uploading an existing file** → перетащите ВСЁ содержимое
   этой папки: index.html, manifest.webmanifest, sw.js, 4 картинки и папку fonts
   (перетаскивайте папку fonts целиком — структура сохранится) → **Commit changes**.
   Важно: файлы должны лежать в корне репозитория, не во вложенной папке,
   а шрифты — внутри папки fonts.
4. **Settings** → слева **Pages** → в блоке Build and deployment:
   Source = **Deploy from a branch**, Branch = **main**, папка **/ (root)** → **Save**.
5. Через 1–2 минуты вверху страницы Pages появится ссылка вида
   `https://ВАШ_ЛОГИН.github.io/forma/` — это адрес приложения.

### Вариант B — Cloudflare Pages

pages.cloudflare.com → Sign up → Create a project → **Direct Upload** →
перетащите папку с файлами → Deploy. Получите ссылку вида `forma.pages.dev`.

Подойдёт и любой другой статический хостинг: это просто статические файлы.

## Шаг 2. Установить на iPhone

1. Откройте ссылку в **Safari** на айфоне.
2. Кнопка **Поделиться** (квадрат со стрелкой) → **На экран «Домой»** → Добавить.
3. Откройте приложение с иконки один раз при включённом интернете —
   за этот запуск оно полностью сохранится на телефоне.
4. Готово. Проверьте: включите авиарежим и откройте приложение — оно работает.

## Данные и резервная копия

- Записи хранятся в памяти приложения на телефоне. У приложения, установленного
  на экран «Домой», iOS эту память не очищает.
- Данные привязаны к устройству: при смене телефона перенесите их копией.
- Копия: вкладка **План → Скопировать данные** → вставьте текст в заметку
  (или пришлите в чат Claude для разбора недели). Восстановление — кнопка
  **Восстановить** там же.
- Если раньше вели записи в версии трекера на claude.ai, перенесите их так же:
  там «Скопировать данные» → здесь «Восстановить».

## Обновление приложения

Замените файлы на хостинге новыми и в файле `sw.js` поменяйте версию в первой
строке кода (например `forma-v1` → `forma-v2`). Приложение подхватит обновление
при следующем запуске с интернетом. Записи при обновлении сохраняются.
